# Falcon Security Scanner

أداة لمسح الثغرات الأمنية في المواقع والتطبيقات

## 🛠️ الميزات
- فحص شامل للثغرات (SQLi, XSS, LFI, RCE)
- واجهة رسومية سهلة الاستخدام
- تقارير مفصلة بالنتائج
- دعم متعدد للأنواع
- سرعة عالية في المسح

## 📁 هيكلية المشروع
```
src/
├── falcon-scanner.py    # الكود الرئيسي
└── utils/               # أدوات مساعدة
docs/                    # ملفات الشرح
requirements.txt         # التبعيات المطلوبة
```

## ⚙️ التثبيت
```bash
pip install -r requirements.txt
```

## 🚀 التشغيل
```bash
python src/falcon-scanner.py
```

## 📋 المتطلبات
- Python 3.6+
- مكتبات حسب requirements.txt
